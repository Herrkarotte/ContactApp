# ContactApp
[![Last Commit](https://img.shields.io/github/last-commit/Herrkarotte/ContactApp/main)](https://github.com/Herrkarotte/ContactApp/commits/main)
## Приложение позволяет:
- Отображать данные о контактах, сохраненных на устройстве в виде списка, пункты которого отображают краткую информацию о каждом контакте.(UserStory1)![Status](https://img.shields.io/badge/Status-✅_Готово-brightgreen).
- Совершать звонок любому контакту из списка по нажатию на этот контакт (UserStory2)![Status](https://img.shields.io/badge/Status-✅_Готово-brightgreen).
  
## Технологии.
### Архитектура.
- MVVM.
### Основные компоненты
- Compose.
- Hilt.
